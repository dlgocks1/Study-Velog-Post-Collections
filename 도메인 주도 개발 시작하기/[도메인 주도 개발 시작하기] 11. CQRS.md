## 11.1 단일 모델의 단점

**명령과 조회는 성격이 다르다**
핵심은 상태를 바꾸는 일과 데이터를 보여주는 일의 요구가 근본적으로 다르다는 것

- 명령(Command): 주문 취소, 상품 등록처럼 상태를 바꾼다. 도메인 규칙·불변식을 지켜야 하므로 애그리거트 단위의 잘 캡슐화된 모델이 필요하다.
- 조회(Query): 화면에 데이터를 보여준다. 여러 애그리거트의 데이터를 한 화면에 모아 보여줘야 하는 경우가 많다. 도메인 규칙은 필요 없고, 화면에 맞는 형태의 데이터가 필요하다.

![](https://velog.velcdn.com/images/cksgodl/post/70c6686e-afc1-4630-872f-cff4a51ecf6b/image.png)

> CQRS ≠ 이벤트 소싱, 그리고 DB를 꼭 나누는 것도 아니다: 
>
CQRS를 처음 접하면 "명령 DB와 조회 DB를 물리적으로 분리하고 이벤트로 동기화하는 무거운 아키텍처"로 오해하기 쉽다. 그건 CQRS의 극단적 형태이고, 이 책이 말하는 CQRS는 훨씬 가볍다
같은 DB를 쓰되, 명령용 모델(JPA 애그리거트)과 조회용 모델(DTO/뷰)을 코드 수준에서 나누는 것으로 충분

## 11.2 CQRS

CQRS의 본질은 하나 —> 명령 모델과 조회 모델을 나눈다.

- 명령 모델 (Command Model): 상태 변경이 목적. 도메인 규칙·불변식을 지켜야 하므로 지금까지 만든 애그리거트·리포지토리·도메인 서비스를 그대로 쓴다. 캡슐화가 중요하다.
- 조회 모델 (Query Model): 데이터 표시가 목적. 도메인 규칙이 필요 없으므로 화면에 맞는 DTO를 직접 만든다. 여러 테이블을 조인하든, 네이티브 쿼리를 쓰든 조회에 최적화된 자유로운 형태를 쓴다.

![](https://velog.velcdn.com/images/cksgodl/post/4bafd541-6d49-4018-8835-cf1a603cb350/image.png)

### 동일 구현체를 활용할 필요는 없다.

![](https://velog.velcdn.com/images/cksgodl/post/e91c93ae-e905-4074-b6f3-d6a2f90536bb/image.png)


같은 시스템에서 구현체를 섞어 쓸 수 있다.

- 명령 모델: JPA + 애그리거트로 주문을 저장/변경 (불변식 지켜야 하므로 JPA의 엔티티 캡슐화가 유리)
- 조회 모델: 복잡한 주문 상세 화면은 MyBatis로 직접 SQL을 짜서 필요한 컬럼만 딱 뽑아 DTO에 채움


- 명령 모델: JPA로 상품 정보를 저장 (관계형 DB, 트랜잭션 필요)
- 조회 모델: 상품 검색 화면은 Elasticsearch(NoSQL/검색엔진)로 조회 (전문 검색·빠른 필터링에 최적)

각 기술의 강점만 골라 쓸 수 있기 때문에 이런 형식 활용.

- MyBatis: JPA는 복잡한 조인·통계 쿼리를 표현하기 불편할 때가 있다. 조회 성능 튜닝도 쉽다
- NoSQL (예: Elasticsearch, MongoDB): 관계형 DB가 약한 영역 
  — 전문 검색, 대량 데이터 집계, 화면 형태 그대로의 문서 조회 — 에서 훨씬 빠르다.

### 분리 수준은 스펙트럼이다

CQRS는 "얼마나 분리하느냐"에 따라 여러 단계가 있다.

- 모델만 분리 (같은 DB): 가장 흔하고 실용적. 명령은 JPA 애그리거트, 조회는 같은 DB를 DTO/뷰로 읽는다. 이 책이 주로 다루는 수준.
- 저장소까지 분리: 명령 DB와 조회 DB를 물리적으로 나누고, 명령 결과를 이벤트로 조회 DB에 반영(동기화). 조회 부하가 크거나 조회 최적화 저장소(검색엔진, OLAP)가 필요할 때.
  - ES, Druid...

> 명령과 조회의 일관성 수준을 다르게 가져갈 수 있다:
> 
> CQRS의 숨은 이점은 일관성 요구를 양쪽에 다르게 적용할 수 있다는 것이다. 명령 쪽은 강한 일관성(트랜잭션·불변식)이 필수지만, 조회 쪽은 약간 오래된 데이터를 보여줘도 되는 경우가 많다. 
>
>저장소를 분리하는 CQRS에서는 조회 모델이 명령보다 살짝 뒤처지는 결과적 일관성을 허용하는데(이벤트로 나중에 동기화되므로), 이게 오히려 조회 성능을 크게 끌어올린다.
